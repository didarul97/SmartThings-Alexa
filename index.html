    Backup and restore

    A backup holds the guest list, the entry log and these settings. Save one before the event starts and after it ends, or to move the desk to another device.

    Data and privacy

    The guest list and the entry log are personal data. They are processed only inside this browser and are never sent anywhere by this page. Clear them from the device once the organiser has the exported log.

    Built-in list
    IIC International Regulators Forum 2026 participant list (Kuala Lumpur, 12–13 October 2026): 95 names from the organiser's PDF dated 2026-10-10. It is stored encrypted inside this page (AES-256-GCM, key derived from the desk passcode) and unlocked once per device with the passcode. If removed, reload it from the Guest list tab.
    Name matching
    Titles and particles are removed, common transliteration variants are unified, then each name part is compared with a Jaro–Winkler similarity so near-spellings still match. Exact, Close and Possible indicate how strong the match is.
    Country matching
    Names, ISO alpha-2 and alpha-3 codes and common short forms (UK, USA, UAE, KSA, Korea) are resolved to the same country before comparing.
    Works offline
    Once the list is loaded, everything runs without a connection. Excel import needs the SheetJS library, which loads from the internet once; CSV and pasted rows never need it.
